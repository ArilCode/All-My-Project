All My Project

Website portfolio yang auto sync dengan GitHub API. Menampilkan semua project yang saya deploy di Vercel secara real-time.

[Live Demo](https://all-my-project-theta.vercel.app/) · [Report Bug](https://github.com/arilcode/REPO/issues) · [Request Feature](https://github.com/arilcode/REPO/issues)

---

✨ Features

- **🔄 Auto Sync GitHub API** - Ambil data repo otomatis tanpa manual update
- **🎨 Dark Theme Modern** - UI dengan gradient biru-ungu `#3b82f6` to `#8b5cf6`
- **📱 Fully Responsive** - Mobile first, aman di HP & Desktop  
- **🖼️ OG Image Support** - Thumbnail keren pas di share ke WA, LinkedIn, Discord
- **⚡ Deployed on Vercel** - Auto deploy tiap push ke GitHub + Edge Network
- **⭐ Custom Favicon** - Icon `Rill` dengan background gradient

🛠️ Tech Stack

- **Frontend**: `HTML5` `CSS` `JavaScript`
- **API**: `GitHub REST API v3`
- **Deployment**: `Vercel`
- **Font**: `Inter`
